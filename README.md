# Sistema de Controle de Notas

Aplicação web educacional para cadastrar alunos por turma, registrar notas e acompanhar os resultados finais.

## Funcionalidades

- Login demonstrativo para acesso do professor
- Cadastro e organização de alunos por turma
- Salvamento de notas parciais
- Cálculo da média de quatro notas
- Classificação em aprovados, recuperação ou reprovados
- Persistência dos dados no `localStorage` do navegador
- Interface responsiva

## Como executar

Abra `login.html` usando uma extensão de servidor local, como o Live Server do VS Code.

Credenciais demonstrativas:

- ID: `professor`
- Senha: `1234`

## Tecnologias

HTML, CSS e JavaScript puro.

## Observação

Este é um projeto educacional. A autenticação é feita no JavaScript do navegador e não deve ser usada para proteger dados reais. Os dados cadastrados ficam armazenados localmente no navegador.
